Tool AI

Tool AI is the current project I am working on. It turns plain-English prompts into real working web tools, so people can describe what they need instead of writing code or hiring a developer.

It is designed for people who are not techy. For example, a user could ask Tool AI to make a student homework tracker that updates when a teacher posts a new assignment with a due date, a dollar-to-Bitcoin calculator, or a grocery tracking tool.

The current public link may sometimes be down while hosting and beta testing are being worked out.

Visit toolai.us Read docs
